Calibration?

  1. Click Start, then walk/run up to your max comfortable speed.
  2. Click Copy → Max pps to set that as the joystick-100% point.
  3. Click Stop, then fine-tune the shape with the Speed Curve below. Save when done.

VR?

Output (gamepad / VR / both) is now set per game in the Game tab. VR needs SteamVR + the Maratron driver; gamepad needs ViGEmBus. The VR device role is Treadmill (keeps both controllers); override for debugging with the --vr-role launch flag.
